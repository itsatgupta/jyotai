# Codex Prompt 09 — Knowledge Framework

Build the knowledge framework without pretending to have complete astrology knowledge.

Requirements:

- source metadata format
- rule metadata
- rule version
- domain
- source/reference
- optional quotation/notes
- provenance

Create directories for:

- career
- business
- wealth
- marriage
- property
- education
- family
- general

Do not populate hundreds of rules.

Create 1-2 example rules only, clearly marked as examples/placeholders until validated against chosen sources.

Document how future rules will be added and tested.
