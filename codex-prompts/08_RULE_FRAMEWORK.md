# Codex Prompt 08 — Rule Engine Framework

Read docs/RULE_ENGINE.md.

Build a generic astrology rules engine.

Requirements:

- rule schema
- rule loader
- rule evaluator
- condition evaluation
- strength calculation
- evidence output
- rule versioning
- unit tests

Start with a few NON-PREDICTIVE demonstration rules against synthetic chart facts so that the framework can be tested.

Do not invent a large astrology rule set.

Do not use an LLM to create runtime rules.
