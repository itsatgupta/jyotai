# Codex Prompt 19 — Production Readiness Review

Do a code review of the complete repository.

Check:

- architecture
- security
- test coverage
- deterministic calculations
- timezone handling
- data privacy
- dependency licensing
- AI hallucination risks
- API errors
- database migrations
- logging
- performance
- prompt injection
- model provider abstraction

Do not make large changes automatically.

First produce a prioritized review:

P0 = must fix before MVP
P1 = should fix
P2 = later improvement

Then wait for approval before implementing P0/P1 changes.
